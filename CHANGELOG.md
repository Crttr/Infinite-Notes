# История изменений

## [0.5.0] — готовится

- Исправлена изоляция данных между локальными проектами (проверено пользователем).
- Оптимизировано разделение frontend-бандла Vite.
- Системное подтверждение импорта `.inotes` заменено на окно приложения.
- Улучшены механизмы проверки архивов и сохранения; базовые сценарии импорта и экспорта проверены вручную.
- Подготовлены CI-сборки Linux AppImage и DEB; обе собираются, запуск на Linux пока не проверен.
- Проведён пользовательский нагрузочный тест с большим количеством изображений; при перетаскивании изображения возможна просадка FPS.

### Перед публикацией

- Проверить финальный Windows-установщик и восстановление проектов из резервной копии.
- При появлении Linux-среды проверить запуск и сохранение в AppImage и DEB.
- Добавить финальную иконку отдельным изменением.
