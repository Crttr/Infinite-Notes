# Infinite Notes

Infinite Notes — локальное Windows-приложение для заметок, визуальных референсов и связей на бесконечном холсте.

## Возможности

- Заметки с форматированным текстом и вложенными списками.
- Свободные галереи и самостоятельные изображения на холсте.
- Перемещение и изменение размеров заметок и изображений.
- Связи между заметками и пунктами списков.
- Undo / Redo для действий на холсте.
- Локальные проекты, экспорт/импорт `.inotes`, резервные ZIP.

## Горячие клавиши

| Клавиши | Действие |
|---|---|
| Ctrl + S | Выбрать файл для сохранения `.inotes` |
| Ctrl + Z | Отменить действие |
| Ctrl + Shift + Z | Повторить отменённое |
| Ctrl + F | Поиск |
| Delete | Удалить выделенный объект на холсте |
| Tab / Shift + Tab | Отступ или уровень списка в редакторе |
| Ctrl + Shift + 7 / 8 | Нумерованный / маркированный список |
| Двойной ЛКМ | Редактировать заметку |

## Разработка

Требуются Node.js, npm, Rust и инструменты сборки Tauri 2 для Windows.

```powershell
npm.cmd ci
npm.cmd run tauri:dev
```

Сборка: `npm.cmd run build`, `npm.cmd run tauri:installer` или `npm.cmd run tauri:portable`.

Подробности: [Release Notes](RELEASE_NOTES_v0.3.0.md).

## Хранение данных

Проекты автоматически сохраняются локально. Для переноса или резервного хранения вручную экспортируйте `.inotes` или ZIP. Не удаляйте данные приложения без резервной копии.
