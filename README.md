# Infinite Notes

**Infinite Notes** — приложение для организации заметок, изображений и связей на бесконечном холсте.

> Статус: проект в разработке. Этап 16 — встроенная справка и документация. Windows Portable ZIP и Setup.exe запланированы на следующий этап; это пока не готовый установщик.

## Возможности

- Бесконечный холст: создание, перемещение, сворачивание и удаление заметок.
- Связи между заметками, настройка формы, цвета, толщины, стрелок и типа линий.
- Связи отдельных пунктов списка с другими заметками и навигация по ним.
- Поиск по названию и содержимому заметок.
- Форматирование текста в Tiptap: жирный, курсив, подчёркивание, зачёркивание, цвет и выделение.
- Многоуровневые списки, сворачивание подпунктов и плавающая панель форматирования.
- Изображения в заметках и отдельные заметки-галереи.
- Широкий редактор и полноэкранный режим.
- Шесть цветовых тем.
- Экспорт и импорт ZIP-резервных копий, включая изображения.
- Встроенная справка по кнопке **? Справка**.

## Запуск из исходников

Требуются Node.js и npm, совместимые с версиями Vite и TypeScript в `package.json`.

```powershell
npm install
npm run dev
```

На Windows PowerShell, если выполнение `npm.ps1` запрещено политикой, можно использовать `npm.cmd install` и `npm.cmd run dev`.

Проверка сборки:

```powershell
npm run build
```

Затем открой адрес, который покажет Vite (обычно `http://localhost:5173/`).

## Краткое руководство

1. Нажми **+** в нижней панели, чтобы создать заметку, или **▦** для галереи.
2. Используй правую кнопку мыши на заметке для редактирования, создания связи или удаления.
3. В редакторе используй панель форматирования, списки, кнопку изображения и **⛶ На весь экран**.
4. Для связи пункта списка установи курсор в пункт и выбери **🔗 Связать пункт**.
5. Открой **⚙ Настройки** для выбора темы, настройки линий и работы с резервными копиями.
6. Нажми **? Справка** для подробных инструкций внутри приложения.

### Управление

| Действие | Управление |
|---|---|
| Поиск | Ctrl+F вне редактора |
| Закрыть поиск | Escape |
| Масштаб холста | Колёсико мыши |
| Контекстное меню | Правая кнопка мыши на заметке или связи |
| Вложенность пункта | Tab / Shift+Tab в списке |

## Данные и резервные копии

Заметки, связи и настройки хранятся локально в браузерном хранилище; изображения — в IndexedDB. **Копирование исходников проекта не переносит пользовательские данные.**

Для переноса проекта открой **Настройки → Резервные копии**, экспортируй ZIP и сохрани его отдельно. При импорте проверь содержимое архива: восстановление заменяет текущие данные. Перед импортом создай свежую копию.
