# Infinite Notes

Infinite Notes — локальное настольное приложение для заметок, визуальных референсов и связей на бесконечном холсте.

## Возможности

- Заметки с форматированным текстом и вложенными списками.
- Галереи и отдельные изображения на холсте.
- Перемещение и изменение размеров заметок и изображений.
- Связи между заметками и пунктами списков.
- Undo / Redo для действий на холсте.
- Локальные проекты, экспорт и импорт `.inotes`, резервные ZIP.

## Платформы

- **Windows:** сборка и пользовательское тестирование выполнялись на Windows; установщик NSIS.
- **Linux (x86_64):** CI успешно собрал AppImage и DEB; запуск и функциональное тестирование в Linux ещё не подтверждены.

## Горячие клавиши

| Клавиши | Действие |
|---|---|
| Ctrl + S | Выбрать файл для сохранения `.inotes` |
| Ctrl + Z | Отменить действие |
| Ctrl + Shift + Z | Повторить отменённое |
| Ctrl + F | Поиск |
| Delete | Удалить выделенный объект на холсте |
| Tab / Shift + Tab | Отступ или уровень списка в редакторе |
| Ctrl + Shift + 7 / 8 | Нумерованный / маркированный список |
| Двойной ЛКМ | Редактировать заметку |

## Разработка

Нужны Node.js, npm, Rust и системные зависимости Tauri 2 для выбранной ОС.

```bash
npm ci
npm run tauri:dev
```

Проверка frontend: `npm run build`.

Windows NSIS: `npm run tauri:installer`.

Linux AppImage/DEB: `npm run tauri -- build --config src-tauri/tauri.linux.conf.json` (из корня проекта; для проверки используйте существующий workflow `.github/workflows/linux-packages.yml`).

## Данные и резервные копии

Проекты хранятся локально. Для переноса и резервного хранения экспортируйте `.inotes` или ZIP. Перед обновлением приложения создайте резервную копию важных проектов. Не удаляйте данные приложения без резервной копии.
