# Infinite Notes — Linux Compatibility + Release Preparation

## Назначение
Это адресный патч для подготовки Linux AppImage/DEB и сохранения Windows NSIS. Он **не закрывает автоматически этапы 4–7**: нужны тесты данных, производительности и реальная Linux-сборка.

## Состав
- `src-tauri/tauri.conf.json`: заменены Windows-специфичные `npm.cmd` на кроссплатформенные `npm`. Windows NSIS остаётся в базовой конфигурации.
- `src-tauri/tauri.linux.conf.json`: отдельные настройки Linux (AppImage/DEB и PNG-иконки), без изменения Windows-сборки.
- `.github/workflows/linux-packages.yml`: ручная и теговая сборка Linux в GitHub Actions с публикацией артефактов.
- `docs/LINUX_VALIDATION.md`: команды и критерии проверки.

## Установка
1. Сохраните резервную копию исходников и отдельные `.inotes` важных проектов.
2. Распакуйте архив **в корень репозитория**, где лежат `package.json` и `src-tauri/`.
3. Проверьте `git diff` и убедитесь, что `src-tauri/tauri.conf.json` не содержит более новых локальных изменений (патч построен на предоставленном файле версии 0.4.1).
4. На Windows: `npm.cmd run build`, затем `npm.cmd run tauri:dev`. Для установщика: `npm.cmd run tauri:installer`.
5. В GitHub: Actions → Linux AppImage and DEB → Run workflow. При наличии ошибок скачайте логи; при успехе скачайте артефакты.

## Важно
- Патч не меняет версию `0.4.1` на `0.5.0` до подтверждения тестов.
- Исходный `src-tauri` должен быть закоммичен в GitHub; без него Linux workflow не соберётся.
- Сборка и запуск Linux **не проверены** в текущей среде.
- Для тестирования приложения после сборки потребуется реальный Linux (или VM) с графическим окружением.
- Не публикуйте релиз до тестов импорта/экспорта `.inotes`, сохранения проектов и нагрузочного сценария.
