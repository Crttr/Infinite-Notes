# Infinite Notes v0.5.0 — этапы 4–7 (проверяемый патч)

## Установка

1. Сохраните текущий исходный проект и отдельно экспортируйте важные `.inotes`.
2. Закройте Infinite Notes.
3. Скопируйте `src/Backup.ts` из архива в корень проекта с заменой.
4. Скопируйте `.github/workflows/ci.yml` и документы из `docs/` в корень проекта.
5. Выполните `npm.cmd ci`, затем `npm.cmd run build` (Windows).
6. Проверьте импорт существующих `.inotes` с изображениями, отмену импорта и переключение проектов.

## Этап 4 — сохранение и архивы

Реализована дополнительная проверка ZIP: совпадение локального и центрального заголовков, имени файла, метода, размеров и CRC, а также границ каталога. Это уменьшает риск принятия повреждённых архивов. Формат существующих `.inotes` не меняется. Существующий механизм резервного копирования и отката сохранён.

НЕ подтверждено: полная транзакционность localStorage и IndexedDB при аварийном выключении; для неё нужны отдельные интеграционные тесты на Windows.

## Этап 5 — производительность

В текущем бэкапе уже присутствуют lazy-компоненты и индексация узлов Map; в этой версии патча мы намеренно не переписываем горячий путь холста без профилирования. См. `docs/PERFORMANCE_TESTS.md`.

## Этап 6 — Linux

В предоставленном бэкапе НЕТ `src-tauri` (включая Cargo.toml, tauri.conf.json, capabilities и Rust-код). Поэтому собирать AppImage/DEB из него невозможно. Workflow проверяет фронтенд; Linux Tauri сборка включится только после добавления src-tauri и соответствующих системных зависимостей. См. `docs/LINUX_RELEASE.md`.

## Этап 7 — релиз

Добавлены релизный чеклист и пример release notes. Версию `package.json` намеренно не меняем с 0.4.1 на 0.5.0 до прохождения проверок. Иконку также не меняем.

## Статус

Этот ZIP — проверяемый патч и подготовка этапов 4–7, НЕ подтверждённый готовый релиз 0.5.0. Сборка приложения и Linux-пакетов в этой среде не выполнялась.
