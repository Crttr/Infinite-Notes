# Infinite Notes v0.3.0 — Release Notes

## Что нового

- Свободная галерея: изображения располагаются на доске, перемещаются, масштабируются, перекрываются и меняют порядок слоёв.
- Управление изображениями прямо внутри карточки галереи без открытия редактора; контекстное меню и автоматическая раскладка.
- Самостоятельные изображения на бесконечном холсте с перемещением и изменением размера.
- Изменение размеров заметок и галерей за стороны и углы.
- История действий: Ctrl + Z отменяет действия на холсте, Ctrl + Shift + Z повторяет отменённое; кнопки на панели.
- Сохранение проекта в файл .inotes через системный диалог (кнопка или Ctrl + S), открытие сохранённых проектов. Локальное автосохранение сохранено.
- Улучшения редактора: Tab/Shift + Tab в списках, отступ в абзацах, Ctrl + Shift + 7/8 для списков.
- Исправления отображения отдельных изображений, управления слоями, выделения и расположения кнопок.
- Обновлённая встроенная справка и версия приложения.

## Важные замечания

- Ctrl + S каждый раз открывает окно выбора файла; файл .inotes не перезаписывается автоматически.
- История Undo / Redo не сохраняется между запусками.
- Для безопасности сделайте резервную копию перед обновлением.
- Релиз предназначен для Windows; сборка под Linux не проверялась.

## Установка

- Portable: распакуйте архив и запустите Infinite Notes.exe.
- Installer: запустите NSIS Setup.exe.
- При обновлении не удаляйте данные приложения без резервной копии.

## Сборка из исходников

```powershell
npm.cmd ci
npm.cmd run build
npm.cmd run tauri:installer
npm.cmd run tauri:portable
```

Проверьте наличие итоговых файлов в `src-tauri/target/release/bundle/nsis/` и `src-tauri/target/release/`. Перед публикацией протестируйте оба варианта на чистой системе.
