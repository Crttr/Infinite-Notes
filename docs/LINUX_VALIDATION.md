# Проверки перед Linux-релизом

1. Windows: `npm.cmd run build`, `npm.cmd run tauri:dev`, `npm.cmd run tauri:installer`.
2. GitHub Actions: запустить `Linux AppImage and DEB` вручную, убедиться в наличии `.deb` и `.AppImage`.
3. Ubuntu 22.04/24.04: установить DEB, запустить программу, создать заметку, добавить изображение, экспортировать `.inotes`, закрыть приложение, повторно открыть проект.
4. AppImage: `chmod +x *.AppImage`, запустить в графической сессии, повторить тесты сохранения.
5. Импорт: обычный, повреждённый и отменённый `.inotes`; проверить отсутствие смешивания проектов.
6. Производительность: 100/500/1000 заметок; зафиксировать время открытия и отзывчивость интерфейса, сравнить Windows/Linux.
7. Версии `package.json`, `Cargo.toml`, `tauri.conf.json` синхронизировать только после прохождения проверок.

При проблемах с AppImage проверьте наличие FUSE и системные зависимости конкретного дистрибутива. Отсутствие FUSE не является доказательством ошибки приложения.
