# Руководство пользователя Infinite Notes

## Создание и поиск

Используй **+** для создания заметки и **▦** для галереи. Поиск открывается кнопкой «⌕ Поиск» или Ctrl+F вне редактора. Поиск работает по заголовку и содержимому.

## Редактор

Открой контекстное меню заметки правой кнопкой мыши и выбери «Редактировать». В редакторе доступны форматирование, списки, вложенность, сворачивание подпунктов, изображения и полноэкранный режим. Изменения подтверждаются кнопкой «Сохранить».

## Связи

Связь между заметками создаётся через контекстное меню заметки. Параметры линий находятся в настройках. Для связи пункта установи курсор внутри пункта списка, выбери «🔗 Связать пункт», укажи заметку и сохрани изменения. Значок 🔗 позволяет выбрать связанную заметку для перехода.

## Изображения

Изображения добавляются из редактора. Отдельные галереи создаются кнопкой ▦. Бинарные данные хранятся в IndexedDB локально.

## Экспорт и восстановление

Настройки → Резервные копии → Экспорт. Для восстановления выбери ZIP, проверь предварительную информацию и подтверди замену данных. Всегда делай резервную копию до импорта.

## Управление

- Ctrl+F — поиск вне редактора.
- Escape — закрытие поиска.
- Колёсико — масштаб холста.
- Правая кнопка мыши — контекстное меню заметки или связи.
- Tab / Shift+Tab — изменение уровня пункта списка.

## Поддержка

Встроенная справка доступна по кнопке **? Справка**. Приложение находится в разработке; перед публикацией релиза проверь сборку и восстановление резервных копий.
